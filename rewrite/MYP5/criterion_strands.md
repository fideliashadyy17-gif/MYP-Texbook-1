# MYP Mathematics 5 — Criterion strand lines (all criterion-mapped tasks)

Same gap as MYP4: the assessment tasks are headed `C R I T E R I O N A/B/C/D ·
<name> <minutes> · <marks>` with instructions, but no strand-mapping line (MYP1 tasks
carry one, e.g. "CRITERIA AND STRANDS A i, ii, iii: …"). The lines below are ready to
insert directly under each task heading.

Scope notes:
- **Chapters 1–10**: four assessment tasks each (A, B, C, D) — 40 lines.
- **Section 12.5 "Cumulative examination"** (end of Chapter 12): one timed 90-minute
  examination divided into four criterion blocks (A 30 min / 20 marks, B 20 min / 12
  marks, C unmarked, D 25 min / 12 marks) — 4 lines.
- **Chapter 11 (capstone modelling project)** has no criterion A–D tasks (it is the
  portfolio project of sections 11.1–11.5), so no lines are needed there.
- The ten in-chapter **modelling tasks** headed `M O D E L L I N G · C R I T E R I O N D`
  already carry the criterion label and run on a Model / Calculate / Interpret / Evaluate
  structure — no strand line is added (same treatment as MYP4).
